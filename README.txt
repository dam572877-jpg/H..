SHAHD — GENTLE EDITION

محتويات النسخة:
- index.html: الموقع كامل.
- صورة شهد الأصلية مدمجة داخل index.html بصيغة Base64؛ لا تحتاج رفع صورة منفصلة ولا يتغير مسارها.
- مشغل أغنية Spotify الرسمي للأغنية المضافة؛ يحتاج إنترنت، وقد يحتاج المستخدم تسجيل الدخول أو تطبيق Spotify حسب إعدادات Spotify.
- CSS وJavaScript داخل index.html؛ لا توجد ملفات بناء أو تثبيت أو خادم مطلوب.

طريقة الرفع إلى GitHub Pages:
1. فك ضغط Shahd_Gentle_GitHub_Ready.zip.
2. افتح مستودع GitHub الخاص بالموقع.
3. ارفع index.html إلى المجلد الرئيسي (Root) بجانب README.txt.
4. اختر Commit changes.
5. من Settings > Pages اختر Deploy from a branch.
6. اختر main ثم /(root) ثم Save.
7. انتظر اكتمال النشر وافتح رابط GitHub Pages.

ملاحظات مهمة:
- لا ترفع ملف ZIP نفسه إلى المستودع؛ ارفع الملفات الموجودة بداخله.
- الصورة مدمجة داخل الصفحة بالفعل، فلا تحذف أو تعدل جزء الصورة داخل HTML.
- الأغنية تعمل من Spotify Embed؛ لا يتم تنزيل أو تضمين ملف الأغنية داخل الموقع.
- خطوط Google Fonts اختيارية وتحتاج إنترنت، وهناك خطوط بديلة عند عدم توفرها.
